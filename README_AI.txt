خمّنها 5.0 - الذكاء الاصطناعي الحقيقي

1) ثبّت Node.js على الكمبيوتر.
2) افتح الطرفية داخل مجلد Khammin_v4.
3) نفّذ:
   npm install
4) انسخ .env.example إلى ملف جديد اسمه .env
5) افتح .env وضع مفتاح OpenAI الخاص بك:
   OPENAI_API_KEY=مفتاحك
6) شغّل:
   npm start
7) افتح في المتصفح:
   http://localhost:3000

مهم: لا تضع مفتاح API داخل app.js أو index.html، ولا ترفق ملف .env عند مشاركة المشروع.
